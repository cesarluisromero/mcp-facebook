# mcp-facebook

Proyecto para administrar páginas, mensajes y anuncios de Facebook desde ChatGPT Work, sobre activos propios y de clientes autorizados.

Estado: implementación inicial, todavía sin despliegue del MCP ni conexión real con Meta. El VPS ya tiene dominio y HTTPS configurados.

Stack propuesto: C#, .NET 10 LTS, ASP.NET Core, SDK oficial de MCP para C# y PostgreSQL, desplegados con Docker Compose.

Consulta el [plan de requisitos, análisis, diseño, implementación, despliegue y evaluación](docs/PLAN.md).

Consulta el [estado de implementación y configuración](docs/IMPLEMENTACION.md).
